How it works

Your first hour, not your first week

The app opens on a built-in guide. On a completely fresh Windows machine, a new teammate follows five steps.

1

Install everything

Git, Perforce and Visual Studio 2022 with the exact workloads Unreal needs. One click each — the app detects what's missing.

2

Get the engine

Verify GitHub↔Epic access, pick a branch, then clone → Setup.bat → GenerateProjectFiles — with live logs and a disk-space check first.

3

Build the editor

Any target, any configuration, real progress bar. ShaderCompileWorker builds automatically, so that classic error never happens.

4

Connect Perforce

Server, login, workspace. Your password is never stored — only Perforce's own session ticket.

5

Sync & Launch

Pull latest → rebuild engine → rebuild project modules → open the editor. Most mornings: one click.

Questions

Straight answers

The things everyone asks before downloading.

Does this include the Unreal Engine source code?

No. The source comes straight from Epic's official GitHub repository using your Epic-linked account, under Epic's own license. This tool automates everything around it — the downloading, dependency setup, building, syncing and launching.

Which engine versions does it work with?

Any UE5 branch on Epic's GitHub: release, 5.x, or ue5-main. You pick the branch in the app.

My teammates aren't build-pipeline people. Will they manage?

That's exactly who this is for. Install, follow the built-in guide, click the buttons in order. Every red item on the Dependencies tab has a button that fixes it.

Windows says "Windows protected your PC"?

It's an unsigned community tool, so SmartScreen warns once — click "More info → Run anyway". The code does nothing your own terminal wouldn't: it drives Epic's official scripts, git, and p4. The source is public if you'd like to check.

Is it really free, or is there a catch?

Really free, forever. It's pay-what-you-want with a €0 minimum — enter nothing and download. If it saves your team a day, a tip is welcome but never required.

Do I need Perforce?

No. Perforce powers the sync features. Without a server you still get dependency setup, engine download, builds, and launching.
